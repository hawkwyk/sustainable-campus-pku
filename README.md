# 北京大学可持续校园实践网站

## 项目简介

这是一个为北京大学"可持续校园实践"课程设计的宣传网站，展示了课程的创新项目、团队成员和可持续发展理念。网站采用现代化的设计，集成了高德地图API，并实现了用户标记自动提交到GitHub Issues的创新功能。

## 核心创新：GitHub Issues集成

### 功能描述
用户在地图上添加的标记会自动提交到GitHub Issues进行审核，无需用户直接访问GitHub。

### 工作原理
1. 用户在地图上选择位置并填写表单
2. 前端收集表单数据和图片
3. 通过API调用创建GitHub Issue
4. Issue包含标记的详细信息、位置和图片描述
5. 管理员在GitHub上审核并手动添加到地图

### 技术实现
- 使用GitHub API v4 (GraphQL)
- Personal Access Token认证
- Base64图片编码传输
- 结构化Issue模板

## 部署说明

### GitHub Pages部署
1. Fork本项目到您的GitHub账户
2. 在仓库Settings中启用GitHub Pages
3. 选择main分支作为源
4. 网站将在几分钟内上线

### 本地开发
1. 克隆仓库到本地
2. 使用Python启动本地服务器：
   ```bash
   python -m http.server 8000
   ```
3. 访问 `http://localhost:8000`
